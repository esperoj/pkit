#+title: pkit wayback

Save URLs to the Wayback Machine using the SPN2 (Save Page Now 2) API.

#+begin_src sh
pkit wayback save https://example.com
#+end_src

* Usage

#+begin_src text
pkit wayback [--key K] [--secret S] [--proxy P] [--lock-file F] [--timeout T] save [URL] [options]
#+end_src

Tool options come before ~save~; save options after it.

| Option               | Default                         | Meaning                                   |
|----------------------+---------------------------------+-------------------------------------------|
| ~--key~, ~--api-key~ | ~$INTERNET_ARCHIVE_ACCESS_KEY~  | Access key                                |
| ~--secret~, ~--api-secret~ | ~$INTERNET_ARCHIVE_SECRET_KEY~ | Secret key                             |
| ~--proxy~            | none                            | Prefix placed before Wayback URLs         |
| ~--lock-file~        | ~/tmp/spn2_submit.lock~         | Serializes SPN2 submissions; ~''~ disables |
| ~--timeout~          | 120                             | HTTP timeout in seconds                   |

Save options (each has a ~--no-~ counterpart):

| Option              | Default | Meaning                                    |
|---------------------+---------+--------------------------------------------|
| ~--capture-all~     | off     | Capture all embedded page resources        |
| ~--capture-outlinks~ | off    | Capture outgoing links                     |
| ~--email~           | on      | Email notification when the job completes  |
| ~--force-get~       | on      | Force GET instead of HEAD                  |
| ~--skip-first~      | on      | Skip if the URL was recently saved         |
| ~--json~            | off     | Output JSON; with stdin, parse JSON payloads |

* stdin

If a URL argument is given, stdin is ignored. If the URL is omitted or
~-~, stdin is read:

#+begin_src sh
echo https://example.com | pkit wayback save
echo '{"url": "https://example.com", "capture_all": true}' | pkit wayback save --json
#+end_src

Plain mode reads the first non-empty line. JSON mode parses objects
(reading ~url~ plus any save options, overriding CLI flags) and scalars;
invalid JSON is treated as a plain URL.

* Output

Plain mode prints the archive URL to stdout. ~--json~ prints:

#+begin_src json
{"url": "...", "archive_url": "...", "job_id": "..."}
#+end_src

Errors go to stderr; exit codes follow the shared contract (2 for usage or
auth problems, 75 when rate-limited or timed out, 1 otherwise).
